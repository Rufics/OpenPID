Calibration round 11, for version 0.94 of the reference tool

1. Unpack everything into one folder.
2. Start version 0.94 of the reference tool anew and wait for its main window
   (Log Viewer). Open nothing in it and leave the window as it comes up. The
   script clicks where that version has its buttons; it fits no other.
3. Double-click run.cmd. After five seconds the script takes the mouse and the
   keyboard: it loads the logs of this folder and saves 22 pictures of the
   tool's windows and 57 plots copied as vector graphics, in about
   9 minutes.
   Leave both alone until it beeps twice.
4. Send back capture-results.zip, which appears next to the script.

To stop it, move the mouse: it stops before its next move.

The copied plots replace what was on the clipboard.

What the files are: *.bbl are the probe logs; manifest.json says what is true
about each; ours.json is what OpenPID computes for them; steps.json
is what the script does, step by step; capture.ps1 is the script.
