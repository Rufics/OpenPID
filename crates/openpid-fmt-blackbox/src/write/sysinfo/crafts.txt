# The example craft of each release: the values of the header lines of
# `lines.txt` for a session that brings none of its own.
#
#   [releases]     the releases the lines below are for
#   name:value
#
# A later section overrides an earlier one. A line that has no value here for
# a release is written only for a session that carries it (the options a
# stock build does not have and no fixture logs: GPS rescue, altitude and
# position hold, optical flow, the build key).
#
# The values are a configuration, not facts of a release. Each family of
# releases has the craft of a real log of `tests/logs/` where that log has
# the line, with linear rates of 1000 deg/s, no debug mode and no GPS
# feature, a board, craft name and start time of our own, and a device
# identifier of zeros. A line the log does not have carries the default of
# the firmware source at the release's tag; the comment above it says where
# it was read. The lines the writer computes for every log (the intervals,
# `looptime`, `vbatref`, `fields_disabled_mask`, ...) are placeholders here.
