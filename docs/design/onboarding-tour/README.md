# Перший запуск: стартовий екран і тур по інтерфейсу

Зауваження замовника (05.11.2026): при першому запуску застосунок має візуально
провести користувача й підказати, як ним користуватись, як у продуктах Adobe і
Microsoft.

## Причина

Порожній стан — голий графік з осями −0,5…0,5 с і підказка в статус-барі зі
зламаним гліфом стрілки. Дванадцять вкладок без пояснення, що з чого починати.
Користувач, який не знає PIDtoolbox, не бачить циклу «лог → шум → фільтри → PID →
застосувати».

## Що кажуть джерела

- **Apple HIG / Material 3 (onboarding):** навчання в контексті, короткими кроками,
  з можливістю пропустити; не блокувати роботу модальними вікнами.
- **NN/g (coach marks):** підказки, прив'язані до елемента, працюють краще за
  «карусель» екранів, яку пропускають; 5–7 кроків — стеля уваги.
- **Adobe/MS:** тур запускається один раз, повторно доступний з меню «Довідка».

## Варіанти

| | Варіант | Плюси | Мінуси | Бали |
|---|---|---|---|---|
| R0 | Як є | — | порожній графік, жодної підказки | 18 |
| R1 | Модальний welcome-діалог із каруселлю 5 екранів | просто зробити | не прив'язаний до UI; закривають не читаючи | 33 |
| R2 | **Coach marks**: затемнення з «віконцем» на елементі + картка з текстом, 7 кроків по справжньому інтерфейсу | навчає в контексті; стандарт Adobe/Figma/GitHub | потрібні прямокутники віджетів і накладання поверх egui | **48** |
| R3 | Постійний чекліст «Перші кроки» у бічній панелі, пункти відмічаються самі | тримає прогрес, не заважає | займає місце; не показує, *де* кнопка | 41 |
| R4 | Підказки-бульбашки на кожній вкладці при першому візиті | дрібними порціями | 12 окремих підказок дратують; нема цілісної картини циклу | 35 |
| R5 | Інтерактивний тур на вбудованому синтетичному лозі (`openpid gen`): тур сам відкриває лог і проходить вкладки | користувач бачить справжні дані | без R2 він пасивний | 44 |

Рекомендація: **R2 + елементи R5** (тур може відкрити синтетичний лог, щоб
показувати кроки на реальних графіках) і **стартовий екран** замість порожнього
графіка.

## Рішення замовника (05.11.2026)

R2 з синтетичним логом із R5; стартовий екран входить у цю ж тему.

## Вимоги до реалізації

**Стартовий екран** (коли жоден слот не завантажений, будь-яка вкладка):
центрована картка 520 px: логотип-назва, «Перетягніть лог сюди або», кнопки
«Open log…», «Open sample log» (генерує сесію `SignalSpec::default()` із seed 1 у
пам'яті, без файлу), «Start the tour», список «Recent files» (до 8, у `Prefs`,
шлях + дата), посилання «User guide». Замість графіка з осями.

**Тур (coach marks).** Стан `Tour { step: usize, active: bool }` в `App`;
`Prefs.tour_done: bool` — тур стартує сам при першому запуску після відкриття
першого логу (або sample log) і більше не стартує; «Help → Show tour» запускає
повторно. Кроки (текст UA/EN через `tr`):

| # | Якір (`anchor id`) | Текст |
|---|---|---|
| 1 | slot bar | «Тут ваші логи. Перетягніть ще один, щоб порівняти» |
| 2 | вкладка Log viewer + епоха | «Оберіть вікно аналізу: перетягніть межі або натисніть Auto» |
| 3 | вкладка Spectrum | «Шум: піки вище 80 Гц — кандидати на notch» |
| 4 | вкладка Freq × throttle | «Шум по газу і гармоніки моторів (RPM overlay)» |
| 5 | вкладка Filter Sim | «Перевірте нові фільтри без польоту» |
| 6 | вкладка Step response | «Відгук на стік: overshoot і затримка» |
| 7 | вкладка Advice | «Поради з доказами й готові команди CLI. Скопіюйте й застосуйте» |

Механіка: кожен крок перемикає потрібну вкладку; якірні віджети реєструють свій
`Rect` щокадру (`app.anchors.insert("tab-spectrum", response.rect)`); поверх UI —
`egui::Area` з `Order::Foreground`: напівпрозоре затемнення (`Color32::from_black_alpha(140)`)
з вирізом (прямокутник якоря + 6 px, скруглення 6), картка 320 px біля якоря
(автоматично зліва/праворуч/знизу, щоб не вийти за вікно) з заголовком «Крок 3 з 7»,
текстом, кнопками «Back», «Next», «Skip». Клавіші: → / Enter — далі, ← — назад,
Esc — пропустити. Touch: кнопки 44 pt. Під час туру решта UI не приймає кліки
(`Area` перехоплює), крім кнопок картки.

**Якірні id** (константи у `tour.rs`): `slot-bar`, `tab-log`, `epoch-handles`,
`tab-spectrum`, `tab-throttle`, `tab-filter`, `tab-step`, `tab-advice`, `advice-cli`.

**Доступність.** Картка туру — `egui::Window`-подібний контейнер з accessible name
«Tour step N of 7»; усі кнопки з іменами.

**Налаштування.** Settings → «Show tour on first start» (чекбокс), «Reset
first-run state».

## Критерії приймання

- Чистий `prefs.json` + відкриття логу → тур стартує; «Skip» записує `tour_done`;
  наступний запуск без туру. Help → Show tour запускає знову.
- Усі 7 кроків показують виріз на правильному віджеті (тест: виріз містить
  `anchors[id]`), перемикають вкладки, клавіші працюють.
- Стартовий екран без логу: кнопки працюють, «Open sample log» створює слот із
  синтетичною сесією (Advice на ній дає пропозицію з overshoot при `damping 0.4`).
- Headless-тести: тур від старту до кінця, Skip, повторний запуск, стартовий екран.
- Скриншоти `start.png` і `tour-3.png` у user guide.

## Розмір

M (≈ 3 дні): стартовий екран — ½, механіка coach marks — 1½, тексти/тести/док — 1.

## Реалізація (06.11.2026, #104)

- `crates/openpid-app/src/tour.rs`: `STEPS` (7 кроків: вкладка, якір, запасний
  якір, текст), `Tour { active, step, cutout }`, `App::{start_tour, end_tour,
  tour_keys, tour_tab, tour_overlay}`. Якорі реєструються щокадру в
  `App::anchors` (`slot-bar` у `slot_headers`, `epoch-handles` — стрічка першого
  слота, `tab-*` — кнопки вкладок, `advice-cli` — поле CLI на Advice); оверлей —
  `egui::Area` у `Order::Foreground` з повноекранним віджетом, який ковтає кліки,
  чотири затемнені прямокутники навколо вирізу, картка 320 px під/над якорем.
- Стартовий екран `views::start_screen` замість вкладки, коли всі слоти порожні
  (`App::start_screen_wanted`); зразковий лог — `App::open_sample`
  (`SignalSpec` 30 с, `damping 0.4`, Betaflight-подібні PID, без файлу);
  `Prefs::{tour_done, show_tour, recent}` (до 8, дата `YYYY-MM-DD` без
  залежностей — `prefs::ymd`); тур стартує з `maybe_start_tour` після першого
  успішного завантаження (`App::auto_tour` вимикає це в тестах).
- Help → Show tour; Settings: чекбокс «Show the tour on the first opened log»,
  «Reset first-run state», «Show tour». Env `OPENPID_TOUR_STEP=n` відкриває
  застосунок одразу на кроці n (скриншоти/демо).
- Тести: прохід усіх 7 кроків із перевіркою, що виріз містить якір і що вкладка
  перемкнулась; Done/Skip/Esc/Back; одноразовість через `prefs.json`; кліки під
  оверлеєм не проходять; Advice на зразковому лозі пропонує D; recent files
  відкриваються зі стартового екрана.

Відхилення: кроки 2 і 7 мають запасні якорі (кнопка вкладки), якщо стрічки чи
поля CLI немає на екрані; широкий віджет (поле CLI) обрізається межею вікна;
`advice-cli` замість окремого кроку для `tab-advice` — одна картка на Advice.
