# ADR-0006: Reference oracles for the mathematics (`openpid-dsp`)

Status: accepted (2026-11-04)

## Decision
- Every `openpid-dsp` function has a test against a fixture generated by `tools/reference/make_fixtures.py` (NumPy 2.5 / SciPy 1.18). The script implements the *specification* of the algorithm independently of the Rust code (for the windows, Welch and rfft directly the SciPy/NumPy functions; for the deconvolution and the heatmap an own implementation of the formulas from `docs/DESIGN.md`). The fixtures (`tests/reference/*.json`, ~0.6 MB) are committed, so CI needs no Python.
- Tolerances: 1e-12 relative for the windows and the FFT, 1e-10 for Welch, 1e-9 for the deconvolution (accumulation in cumsum).
- On top, tests of physical meaning: Parseval, the amplitude of a sine, recovery of a PT1 plant by deconvolution, the metrics of ideal step responses, plausibility of the results on a real log.

## Consequences
- An algorithm change = a script change plus regenerated fixtures in one PR; CI catches a mismatch between them.
- Python stays a dev-only dependency.
