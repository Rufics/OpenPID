# ADR-0006: Еталони для математики (`openpid-dsp`)

Статус: прийнято (2026-11-04)

## Рішення
- Кожна функція `openpid-dsp` має тест проти фікстури, згенерованої `tools/reference/make_fixtures.py` (NumPy 2.5 / SciPy 1.18). Скрипт реалізує *специфікацію* алгоритму незалежно від Rust‑коду (для вікон, Welch, rfft — напряму функції SciPy/NumPy; для деконволюції та heatmap — власна реалізація формул з `docs/DESIGN.md`). Фікстури (`tests/reference/*.json`, ~0.6 МБ) закомічені, тож CI не потребує Python.
- Допуски: 1e‑12 відносно для вікон і FFT, 1e‑10 для Welch, 1e‑9 для деконволюції (накопичення у cumsum).
- На додачу — тести фізичного сенсу: Парсеваль, амплітуда синуса, відновлення PT1‑об'єкта деконволюцією, метрики ідеальних step‑відгуків, правдоподібність результатів на реальному логу.

## Наслідки
- Зміна алгоритму = зміна скрипта + перегенерація фікстур в одному PR; розбіжність між ними ловить CI.
- Python лишається dev‑only залежністю.
